# LiterAlura
El proyecto LiterAlura se basa en la interacción con una API externa especializada en libros: [Gutendex](https://gutendex.com/). Mediante esta API, los usuarios podrán buscar libros por título, autor, idioma y otros criterios. 
Los datos obtenidos de la API, que se encuentran en formato JSON, serán procesados y almacenados en una base de datos local. Esto permitirá realizar búsquedas más rápidas y eficientes en el futuro.

Para facilitar la interacción con el usuario, se desarrollará una interfaz de línea de comandos (consola). Esta interfaz ofrecerá un menú de opciones intuitivo que permitirá a los usuarios realizar diversas acciones.

## ⚙️Tecnologías y herramientas ultilizadas
- Java
- PostgreSQL
- Spring Boot
- Spring Data JPA

## 💻 Funcionalidades Clave de LiterAlura

- Búsqueda de libros por título exacto
- Búsqueda de libros por autor
- Búsqueda de libros por idioma
- Búsqueda de autores vivos en determinado año
- Búsqueda de los top 10 de libros con mayor número de descarga
